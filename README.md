# 秋招手帖

一个在自己电脑上运行的秋招投递工作台。记录投了哪里、到了哪一步，以及下一场笔试或面试是什么时候。

**本地保存 · 无需账号 · 无需购买服务器或域名 · 无第三方运行依赖**

## 快速开始

需要 **Python 3.9 或更新版本**，以及现代浏览器。正常使用不需要 Node.js。

```sh
git clone https://github.com/VanceRUYI/offer-tracker.git
cd offer-tracker
python3 server.py --open
```

浏览器会打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。运行期间保留终端窗口，按 `Control+C` 停止；下次运行同一命令即可继续使用。

macOS 也可以双击项目内的 **启动秋招手帖.command**。该脚本使用 `/usr/bin/python3`；如果 Python 安装在其他位置，请使用上面的终端命令。下载 ZIP 后如提示没有执行权限，可先执行：

```sh
chmod +x 启动秋招手帖.command
```

端口被其他程序占用时：

```sh
python3 server.py --port 8766 --open
```

## 能做什么

| 功能 | 使用方式 |
| --- | --- |
| 记录投递 | 公司、岗位必填，其他信息按需补充；保存后返回列表并短暂突出新记录 |
| 跟进进度 | 点击公司打开详情，通过“添加进展”记录测评、笔试、面试、Offer 等变化 |
| 待办与日历 | 默认查看近 7 天，也能按年月日查看安排；点事项打开对应投递 |
| 日期与时间 | 统一的日期浮层，支持翻月、选择年份、回到今天和输入时分 |
| 投递入口 | 保存官网或岗位链接，之后直接打开 |
| 辅助识别 | 粘贴岗位网址或通知文字，核对识别结果后再填入表单 |
| 搜索与筛选 | 按公司、岗位等关键词搜索，结合阶段、重点关注、企业性质筛选 |
| 导出与备份 | 完整 JSON 备份、CSV 表格导出，以及本地 SQLite 自动快照 |
| 个性化寄语 | 修改首页寄语、侧栏标题和正文，选择同风格图标，支持预览和恢复默认 |

界面适配宽屏表格和窄屏卡片。“看看示例”使用虚构数据，只供预览，不会写入你的记录。

## 日常怎么用

1. **新增投递**：先填公司、岗位，可附投递链接。企业性质、城市、渠道、简历版本和备注放在“更多信息”中。
2. **收到通知**：点击投递记录里的公司名称，选择“添加进展”，更新当前阶段。
3. **记录安排**：在“下一步”填写“参加一面”等事项，再选“安排时间”，就会出现在待办和日历中。
4. **完成后跟进**：在待办或详情中标记完成；完成记录保留在时间线，再添加下一步安排。

每份投递有 **一个当前待办**，可以修改时间或内容；没有时间的事项单独列为“时间待定”。结束投递会清除当前待办，保留历史。

同一公司、同名岗位不能重复创建，不同岗位可以分别记录。企业性质选填；所属行业已从日常界面移除，旧记录中的行业数据仍保留在导出中。

首页点击侧栏寄语旁的编辑按钮，可以修改文字，并从叶子、太阳、星星、爱心、咖啡、指南针中选择图标。编辑时实时预览，保存后生效；“恢复默认”也需要保存。今日和逾期待办仍优先于首页寄语显示。设置保存在本机数据库，刷新后仍保留。

## 网址能自动识别到什么

- 支持部分公开招聘页的标准 JobPosting 信息、明确中文字段和岗位标题，以及粘贴的岗位详情、投递通知、面试邀请。
- 公司、岗位、城市和企业性质需要有明确依据；个人投递日期、进度和安排不会仅凭招聘页面猜测。招聘发布日期不会被当作投递日期。
- 识别结果先展示候选值及依据，勾选填入后仍需点击保存。结果可以修改，不能确定的信息留空。
- 需要登录、动态加载或限制访问的页面可能无法识别，可改为粘贴文字。多个安排、缺少年份或模糊时间需手动核对。

这是辅助录入工具，不是自动投递工具，也不会登录你的招聘账号。网络访问细节见[开发说明](docs/development.md#网络与隐私)。

## 数据存在哪里

默认数据库位于 `data/workbench.sqlite3`，**不在浏览器缓存中**。关闭网页、清理浏览器缓存不会删除它。程序只监听本机回环地址，不向外提供服务。

`data/`、数据库文件、备份、导出文件、环境变量和常见缓存已配置 Git 忽略规则；GitHub 仓库保存代码，不能替代你的投递数据备份。

### 导出与自动备份

- **JSON**：包含完整投递、时间线和个性化设置，可在另一份工作台中合并导入。
- **CSV**：适合用表格查看，不包含完整时间线。
- **自动快照**：每天首次启动时生成 `data/backups/YYYY-MM-DD-daily.sqlite3`；导入和删除前也会生成快照。

JSON 导入只补充新记录：相同编号或同一公司、同名岗位会跳过，**不会覆盖已有记录或合并其后续进展**。目前不直接支持飞书表格或其他工具的备份格式。

个性化设置仅在本机尚未保存过设置时恢复，已有设置会保留；没有个性化字段的旧备份仍可导入。

建议定期把 JSON 另存到其他磁盘或自己的备份位置。同一磁盘上的快照无法防止整盘损坏。

### 从 SQLite 快照完整恢复

1. 关闭工作台服务，在终端按 `Control+C`。
2. 将当前 `data/workbench.sqlite3` 另存留底。
3. 复制需要的 `data/backups/` 快照到 `data/`，命名为 `workbench.sqlite3`。
4. 重新启动工作台，并保留原始快照。

## 当前边界

仅本机使用；没有多设备同步、邮箱自动读取、系统推送或网页关闭后的提醒。日程展示在工作台页面内。前端使用系统字体和本地资源，无需下载字体或组件库。
