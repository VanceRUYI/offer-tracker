# 秋招手帖

个人秋招工作台：本地浏览器界面 + SQLite 数据库。无需服务器、域名、账号或第三方依赖。

## 打开

先克隆项目，或在 GitHub 下载 ZIP 并解压：

```sh
git clone https://github.com/VanceRUYI/offer-tracker.git
cd offer-tracker
```

在 macOS Finder 里双击 **启动秋招手帖.command**。它会打开终端并启动工作台，随后自动打开浏览器。

浏览器地址：[http://127.0.0.1:8765](http://127.0.0.1:8765)

运行时保留终端窗口。按 `Control+C` 停止；下次双击即可继续使用，数据仍然保留。关闭网页不会删除数据。

也可以在此文件夹执行：

```sh
python3 server.py --open
```

需要 Python 3.9 或更新版本。macOS 双击启动脚本使用 `/usr/bin/python3`；如果你的 Python 安装在其他位置，可在终端使用上面的命令启动。端口被其他程序占用时，使用 `python3 server.py --port 8766 --open`。

## 主要功能

- **近期安排**：未来七天日期条，逾期、今天、未来几天、时间待定的事项；可切到全部安排。勾选完成会留下历史记录。
- **投递记录**：公司与岗位必填，其他信息可稍后补充；关键词搜索、阶段筛选、重点关注与排序。
- **投递链接**：新增表单直接填写招聘官网或具体岗位的完整网址，列表和详情可在新标签页打开；未附链接的记录可一键进入补充。宽屏显示表格，窄窗口自动显示投递卡片。
- **辅助识别**：粘贴具体岗位网址，点击“识别网址”；先查看候选字段和依据，勾选填入，核对后再保存。需要登录或无法直接读取的页面，可以复制岗位详情、投递通知或面试邀请，使用“识别文字”。
- **企业分类**：企业性质（央企、国企、民企、外企、合资企业、事业单位、其他）与所属行业（互联网、人工智能、金融、制造业等）分开记录，支持组合筛选。“央国企”筛选同时包含央企和国企；“未填写”方便补齐旧记录。分类显示在公司下方及详情中，也包含在 JSON/CSV 导出内。
- **岗位详情**：右侧展开信息、备注、完整时间线。添加进展可同时修改当前阶段、下一步和安排时间。
- **数据备份**：JSON 保留全部信息和时间线；CSV 便于表格查看，不包含完整时间线。
- **示例预览**：虚构记录仅用于了解界面，不能修改，也不会写入真实数据库。

同一公司、同名岗位不能重复创建；不同岗位各自记录。结束投递时会清除当前待办，保留历史。

### 识别范围

- 公开页面支持标准 JobPosting 招聘信息、明确的中文字段，以及部分岗位标题格式；没有通用网站登录或动态页面浏览能力。
- 公司、岗位、城市有明确依据时提供候选值；个人投递日期、进度只从明确标注的申请信息中提取。招聘发布日期单独展示为参考，不会填成投递日期。
- 企业分类识别支持“企业性质：民营企业”“所属行业：互联网”等明确字段，以及网页 JobPosting 的行业信息。识别结果提供原文依据，可勾选后填入或手动选择；不按公司名、岗位名、客户或母公司性质猜测。未支持、冲突或不明确的值留待确认；“上市公司”不自动转换成民企或国企。旧数据无需迁移，原有分类为空。
- 邀请或申请通知中的单项笔试、面试安排支持识别到分钟；缺少年份、时间范围、多项安排等情况留待核对。公共招聘安排不会直接生成个人待办。
- 识别不会创建记录。已有字段默认不勾选覆盖；新增记录的默认日期和阶段可由明确结果替换。未识别到进度时显示“待确认”建议，实际投递日期仍需核对。
- 网页读取只访问公开 HTTP/HTTPS 地址，不携带浏览器登录状态。当前电脑配置代理且使用 Fake DNS 时，通过 Google Public DNS 的 [DoH JSON API](https://developers.google.com/speed/public-dns/docs/doh/json) 解析域名，再经已有代理连接验证过的公网 IP；仅发送域名给 DNS 服务，不发送岗位路径、通知或本地投递记录。失败时可使用文字识别，文字处理完全在本机完成。

## 数据与备份

真实数据在 `data/workbench.sqlite3`，不在浏览器缓存中。程序只监听本机回环地址，不对外提供服务。

- 每天首次启动时生成一份 `data/backups/YYYY-MM-DD-daily.sqlite3`。
- 导入和删除前自动生成额外快照。
- 备份页的 JSON 导出可在另一份工作台中合并导入；相同编号或相同公司、岗位会跳过，**不会覆盖已有记录，也不会把同一投递的更新合并回去**。
- 旧版 HTML 工具、飞书表格暂不支持直接导入；首版支持本工作台的 JSON 备份。
- 建议另存一份 JSON 到其他磁盘或你自己的备份位置。同一磁盘上的快照不能防止整盘损坏。

### 从 SQLite 快照完整恢复

1. 关闭正在运行的工作台（终端按 `Control+C`）。
2. 把当前 `data/workbench.sqlite3` 另存留底。
3. 将需要的 `data/backups/` 快照复制到 `data/`，命名为 `workbench.sqlite3`。
4. 重新启动。原始快照请保留。

## 第一版边界

仅本机使用；没有手机同步、邮箱自动读取、后台通知或网页关闭后的提醒。日程在工作台页面内展示。
每个岗位有一个当前待办，完成的待办进入时间线。后续可以按实际使用需求调整。

## 开发与验证

文件职责：`store.py` 数据校验、事务、备份；`server.py` 本地 HTTP 接口；`recognition.py` 网页读取与保守字段识别；`web/app.js` 界面交互；`web/model.mjs` 日期与筛选；`web/styles.css` 视觉样式。

```sh
python3 -m unittest test_store test_server test_recognition -v
node --test web/model.test.mjs
node --check web/app.js
```

测试使用临时数据库，不会写入真实投递。Node 只用于开发测试，正常使用不需要 Node。
