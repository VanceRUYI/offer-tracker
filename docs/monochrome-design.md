# 黑白界面修订

针对第一版蓝灰界面和系统下拉菜单的反馈，改用白色页面、深色文字、细分隔线和克制的状态色。侧栏与顶栏回归固定边界，统计区采用数字与分隔线，减少悬浮卡片、磨砂、渐变和胶囊装饰。

## 下拉控件

- 所有单选菜单采用统一白色弹层、选中勾选和轻量悬停反馈。
- 保留原生 select 作为表单值来源；与筛选、状态更新、识别填入同步。
- 支持方向键、首尾跳转、字符查找、回车选择、Escape 关闭、Tab 离开。
- 根据视口自动向上或向下展开；窄屏保持菜单在可视范围内。
- 在编辑弹窗内创建菜单，避免被模态层遮挡；离开焦点、滚动或切换页面时关闭。

## 验证

- Python 回归测试 31 项、前端模型测试 5 项通过。
- 检查 JS 语法与 git diff 空白错误。
- 浏览器验证了鼠标筛选、键盘选择与关闭、搜索快捷键隔离、表单值同步及识别填入。
- 检查 1280px、432px 和 360px 布局；360px 页面无水平溢出，菜单保持在视口内。
- 使用只读示例和未保存的测试表单，未写入测试投递。

## 版本与回退

本次修订保存在 `codex/refined-monochrome-ui`。第一版银蓝界面保存在 `codex/apple-inspired-ui`，最初版本为 `v1-before-apple-redesign`（亦为当前 main）。切换已有分支或标签即可恢复对应界面；数据库不受界面版本切换影响。此次未推送远端。

## 字体、比例与色温微调

用户认可黑白方向后，继续在同一布局上微调：

- 标题从最大 48px、650 字重收为最大 38px、600 字重，中文负字距减小；窄屏标题采用 28–30px。
- 公司、岗位、日期、安排与表单文字增大，正文与辅助信息保持清晰层次。继续使用本机系统字体，无外部字体下载。
- 桌面顶栏从 84px 收为 76px，统一左右对齐，减少标题区和表格行内的空白；窄屏统计区也略微收紧。
- 页面使用近白 `#fafaf8`，白色内容卡片、暖灰侧栏和炭黑按钮；低饱和灰橄榄色 `#626e50` 只用于导航、菜单选中、日期和阶段等局部。
- 本轮为 CSS 与浏览器主题色调整。浏览器检查桌面投递表、近期安排、窄屏表单及菜单；360px 视口没有页面横向溢出，菜单右边界保持在 348px。

微调前的纯黑白版本保留在提交 `b52c9ed`，可单独回退本轮样式。

### 比例回退

根据用户后续反馈，字号、字体、字重、字距、行距及布局尺寸和间距已恢复到 `b52c9ed`。保留暖灰与灰橄榄配色微调。

### 组件内部比例微调

保留认可的页面布局与字体，仅统一相邻控件：顶部搜索和新增按钮高 42px；筛选按钮和下拉框高 36px；表格阶段控件宽 84px、高 28px；表单输入与下拉框高 46px、圆角 10px。桌面企业分类控件最小宽度 112px，窄屏继续自适应。浏览器检查了实际尺寸、企业筛选和表单显示。
