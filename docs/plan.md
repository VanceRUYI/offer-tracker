# 秋招工作台 · 第一版

用户已确认本地浏览器 + SQLite，授权自主完成第一版后再调整。

## 产品与设计

页面：近期安排、全部投递、数据备份；岗位详情用侧边抽屉，进展和编辑用原生对话框。
快速新增只必填公司、岗位。进展追加为时间线，同时修改当前阶段与下一步；历史记录不能被覆盖。
每个岗位保留投递日期、城市、优先级、渠道、岗位链接、简历版本、备注。
支持搜索、阶段/优先级筛选、排序、待办完成、删除确认、JSON 合并恢复、CSV 导出。
首次打开真实记录为空，可切换只读示例预览。示例不写入真实数据库。

视觉：冷白 #F7F9FA、纸白 #FFFFFF、墨色 #182C29、深绿 #176653、辅助灰 #71817D、琥珀 #AD6724。
界面主体使用系统中文无衬线，标题克制使用宋体，日期和统计使用等宽数字。
左侧 220px 导航，内容最大 1280px；本周七日条呈现有安排的日期，待办列表是首页主体。
窄屏压缩导航与双栏，表格在自身容器横向滚动。焦点可见、原生模态焦点约束、减少动态效果。

## 实现

Python 3.9+ 标准库 HTTP 服务与 SQLite，无安装依赖；静态 HTML/CSS/JS。
只监听 127.0.0.1:8765，验证 Host、Origin 和写请求自定义头，只公开明确列出的静态资源。
数据库存放在 data/workbench.sqlite3；自动每日快照及导入前快照；忽略所有个人数据和备份。

- [x] 数据层：store.py；真实临时数据库验证持久化、重复、时间线、恢复事务与备份。
- [x] HTTP：server.py；验证增改查删、导出、非法请求、数据目录不可访问。
- [x] 界面：web/index.html、styles.css、app.js、model.mjs；日期/筛选逻辑由 Node 行为测试验证。
- [x] 交付：启动秋招手帖.command、README.md；语法检查、自动化测试、HTTP 冒烟检查，提交本地页面打开请求。

## 验证备注

代码审查发现导出无大小限制而导入限制 5 MiB，会使合法备份无法恢复；已移除导入大小及记录数的人为上限，新增 90 条、每条 20,000 中文字符笔记的 HTTP 恢复用例。
普通单记录编辑仍受请求大小限制，导入仍需有效格式、逐条校验和事务提交。
WebMCP 在支持的浏览器中渐进注册查询、新增与进展操作；普通浏览器无需此能力。未进行支持环境中的 WebMCP 调用验证。
本轮执行数据层、HTTP 接口、日程与筛选逻辑测试以及资源/语法检查；未进行浏览器截图和交互测试。

## 第二轮：投递入口与小窗口优化

投递链接移出折叠选填区；投递列表增加入口列，详情显示独立链接卡片，未附链接时可直接打开编辑并聚焦链接。
沿用已有 url 字段，无数据库迁移。链接保留查询参数和片段，使用新标签页打开并隔离 opener。
1100px 以下的投递列表自动显示卡片，重点呈现公司、阶段、下一步及链接；保留宽屏表格。
在实际 432px 窗口及临时 1440px 宽屏检查布局、只读示例搜索、详情入口和新增表单；已恢复原窗口大小。实际窄屏文档宽度与可视宽度均为 432px。
临时数据库验证链接创建、重读、修改、导出恢复；真实投递未写入测试记录。

本轮在独立新目录实现，不修改已有简历或用户现有变更。用户要求本地运行，不注册或发布云端站点。

## 第三轮：三项功能对照与辅助识别

用户要求支持网址识别、近七日笔试面试、导出备份。后两项已有实现，补齐网址/文字识别入口。
新增识别接口仅返回预览，不写数据库；候选信息逐项勾选填入现有新增/编辑表单，继续由用户核对保存。
支持 JobPosting 与明确中文字段；实际投递日期与招聘发布日期分开；公共招聘流程不视为个人进度；模糊、多项安排保留为参考。
网络读取限制体积、超时、跳转，拒绝本机/内网地址。代理 Fake DNS 使用独立公网 DoH 验证，再固定目标 IP 并验证原域名 TLS。
新增提取边界、代理目标验证、识别接口无写入测试；保留七日边界和 JSON/CSV 恢复验证。本轮未进行浏览器交互测试。

## 第四轮：企业性质与行业

新增可选 company_type 与 industry，将所有制性质与行业分开；表单可修改，列表轻量标签，详情展示。
提供央国企合并筛选、性质/行业组合筛选、未填写筛选和关键词搜索。分类随 JSON/CSV 导出保存。
读取旧 payload 时补空字段；旧备份可导入并继续编辑，不改动原始历史。
识别仅映射明确性质/行业标签与 JobPosting 行业字段，未知或冲突不推断，沿用可勾选的候选预览流程。
临时数据库验证持久化、更新、旧记录兼容和导入恢复；验证分类边界、组合筛选、HTTP 识别及 CSV 列。
