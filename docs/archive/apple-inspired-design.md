# 银白工作台 · 前端设计

## 方向

参考 [Apple Mac 产品页面](https://www.apple.com/mac/) 的留白、字号层级和克制配色，把秋招手帖整理为适合每日使用的个人工作台。
不引入组件库、字体下载、追踪脚本或图片资源依赖。

- 银白 `#f5f5f7` 画布、白色内容表面、深灰 `#1d1d1f` 正文、蓝色 `#0071e3` 主操作。
- 系统无衬线字体；标题加大、缩短，日期和数字使用等宽数字排列。
- 桌面侧栏独立悬浮，导航和弹层使用轻微半透明材质；正文使用实色表面。
- 宽屏使用投递表格；中等窗口使用卡片；700px 以下使用底部四入口导航。
- 统一按钮、表单、分类标签、详情、空状态和数据备份页。
- 弹窗使用原生 dialog 保留焦点约束和 Escape 关闭行为；动效遵循 reduced-motion，高对比度偏好有实色回退。

## 版本与回滚

旧版保留在 `main`，标记为 `v1-before-apple-redesign`（`d6193de`）。新版在 `codex/apple-inspired-ui`。
只改前端显示，数据文件、数据库结构、识别与导出接口均保持原实现。

需要恢复旧版时，在确认当前修改已提交后切换至 `main`，重新加载网页。`data/` 是忽略目录，切换版本不删除本地记录。

使用只读示例检查 1280px 桌面列表、1050px 双列卡片、432px 底部导航与详情/新增表单，以及 360px 备份页。检查尺寸下文档无横向溢出；分类筛选结果正确。
新增表单仅打开查看，未保存测试投递。前端模型的 5 项测试、JavaScript 语法检查和差异空白检查通过。
